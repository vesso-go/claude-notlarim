# Claude Notlarım

Claude ile gerçek işlerde ne yaptığımı, neyi denediğimi ve neyin işe yaradığını burada topluyorum. Kendi kendine öğrenen bir mühendisin (sunucu, ağ, Node.js, SQL, üretim dijitalleşmesi) kayıtları.

> Mükemmel değil, gerçek. Burada gördüğün şey yayınlanmış hâli, cilalı hâli değil.

## İçindekiler

| Klasör | Ne var |
|---|---|
| `skills/` | Claude'a yüklenebilir hazır skill'ler |
| `docs/` | Yayınlama kontrol listesi, nasıl kurulur notları |
| `CESARET.md` | Korku ve küçük kazanç günlüğüm |

## Skill nasıl yüklenir?

**Claude Code (terminal) kullanıyorsan:**
1. Bu repoyu indir (yeşil "Code" düğmesi, "Download ZIP").
2. `skills/ticarilestir` klasörünü kendi bilgisayarında `~/.claude/skills/` klasörünün içine kopyala.
3. Claude Code'da `/ticarilestir proje-adi` yaz.

**Claude uygulaması / claude.ai kullanıyorsan:**
1. `skills/ticarilestir` klasörünü zip'le.
2. Ayarlardaki Skills bölümünden yükle (menü adı zamanla değişebilir).
3. Sohbette "bunu nasıl paraya çeviririm" de ya da `/ticarilestir` yaz.

## Skill'ler

- **ticarilestir:** Bir fikri müşteri, acı noktası, otomasyon payı, fiyat, 7 günlük test ve risk sorularından geçirip GİT / DEĞİŞTİR / BIRAK kararı verir.
